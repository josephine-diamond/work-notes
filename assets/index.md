# Shared asset index

AI agents must read this file before planning or producing a project.

## Microsoft Azure

Location: `assets/azure/`

- Official Microsoft Azure Architecture Center SVG service icons.
- Keep icons unmodified and pair each icon with its service name.
- Read `assets/azure/usage.md` before use.

## Company

Location: `assets/company/`

- `logos/`: approved company logos.
- `images/`: approved internal images and screenshots.
- `brand.md`: colors, fonts, spacing, and logo usage rules.

Do not invent a company logo or approximate it with styled text. If the required company asset is missing, leave a clear placeholder and request the real file.
